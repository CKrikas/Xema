# Xema Tattoo Website

A professional tattoo artist portfolio website built with ASP.NET Core MVC and PostgreSQL.

## Features

- Tattoo gallery
- Category management
- Entity Framework Core
- PostgreSQL
- ASP.NET Core MVC
- Razor Views

## Planned Features

- Image upload
- Cloudflare R2 storage
- Authentication
- Public gallery
- Responsive design
- SEO optimization
- Merchandise shop
